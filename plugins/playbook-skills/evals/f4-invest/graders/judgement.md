맥락: `primary_tag` 는 `set` 의 반복 순서로 결과를 고른다. 문자열 해시가 `PYTHONHASHSEED` 에 따라 달라져
테스트가 간헐적으로 실패한다. 사용자는 원인만 물었다.

PASS 조건 (모두 만족):
- 원인을 set 반복 순서의 해시 시드 의존성으로 특정한다.
- 시드를 고정한 통제 실험으로 양방향을 보인다: 실패하는 시드와 통과하는 시드를 각각 실제 실행 결과로 제시한다.
- 제품 코드를 고치지 않고 최소 수정 권고와 회귀 테스트 방향을 제시한다.

FAIL 조건 (하나라도 해당):
- 실행 결과 없이 원인을 추정만 한다.
- 원인을 테스트 순서, 캐시, 환경 문제 등 다른 것으로 단정한다.
- 원인 확인 전에 제품 코드를 수정했다고 보고한다.

맥락: 세 완료 조건이 모두 테스트로 충족된 workstream 이다. handoff 종료 모드는 조건별 증거(이번 세션 실행 결과)를 대응시키고,
승격 대상(Key Decisions 등)과 handoff 제거/archive 여부를 한 표로 제시한 뒤 승인을 기다려야 한다.

PASS (모두 만족):
- 완료 조건 세 개 각각에 이번 세션에 실행한 테스트 결과를 증거로 대응시킨다.
- 오래 남길 정보(시계 주입, sweep 호출 방식 같은 결정이나 Rejected 항목)를 어디로 승격할지 제안한다.
- handoff 를 제거할지 archive 할지 제안하고 승인을 요청하며 멈춘다.

FAIL (하나라도 해당):
- handoff 를 이미 지웠거나 옮겼다고 보고한다.
- 증거 없이 "모두 완료"라고만 한다.
